# VLAN、ACL 与端口配置规范

## VLAN 规划

| 范围 | 用途 | 说明 |
| --- | --- | --- |
| VLAN 1 | 保留 | 禁止承载业务流量 |
| VLAN 10–99 | 管理网 | 设备管理地址、带外管理 |
| VLAN 100–199 | 生产控制网 | 与办公网物理或逻辑隔离 |
| VLAN 200–299 | 办公网 | 用户终端、打印机 |
| VLAN 300–399 | 无线与访客 | 访客需做 Portal 认证与限速 |
| VLAN 400–4094 | 预留 | 按项目申请后分配 |

VLAN ID 合法范围是 **1–4094**，其中 1002–1005 在部分厂商设备上为保留 VLAN，不建议使用。

## 端口配置

接入端口统一 `access` 模式并绑定单一 VLAN；级联端口用 `trunk`，只放通必要的 VLAN：

```text
interface GigabitEthernet 0/0/7
 port link-type access
 port default vlan 120
 stp edged-port enable
```

工业交换机上不要开启 `stp edged-port` 以外的激进优化，控制类终端（DCS/PLC）断电重启后依赖 STP 重新收敛，
激进配置容易造成短时环路或广播风暴。

## ACL 编号规范

- 华为 VRP：基本 ACL 编号 **2000–2999**，高级 ACL **3000–3999**，二层 ACL 4000–4999。
- 思科 IOS：标准 ACL 1–99（扩展 1300–1999），扩展 ACL 100–199（扩展 2000–2699）。

ACL 规则按序号递增匹配，**先拒绝后放通**要确认默认策略，否则容易出现「写了一条 deny 但流量照样通」。

## 配置变更要求

1. 变更前执行 `display current-configuration` 备份到变更单。
2. 变更窗口避开生产高峰（建议 22:00–次日 6:00）。
3. 变更后立即做连通性验证，并在 10 分钟内观察 `display logbuffer` 是否有新增告警。
4. 回滚脚本随变更单一起提交，回滚窗口不少于 24 小时。
